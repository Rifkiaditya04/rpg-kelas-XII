# Bahasa Indonesia Micro-Prototype

Playable browser prototype for **KELAS 12 — THE FINAL MISSION**.

## Scope
- 10 Golden Dataset v1 questions
- Four worlds: Career Mission, Film Detective, Drama Stage, Nusantara Explorer
- XP and score
- Progress bar
- Answer feedback and explanation
- Difficulty-aware content seed
- Game-mechanic labels
- Final result screen

## Important
This is a **technical/gameplay prototype**, not production content. The golden dataset remains subject to exact source-page verification and Buku Guru cross-check before mass generation.

Open `index.html` in a browser to play the prototype locally. For a hosted version, publish this folder through GitHub Pages after the repository Pages setting is enabled.
