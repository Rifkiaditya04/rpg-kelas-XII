# ALUR LINEAR PEDAGOGIS (WAJIB DITAATI)
**Konteks:** Aturan ini berlaku mutlak selama fase pembuatan Bank Soal mata pelajaran untuk "Proyek Game Kelas XII".

Setiap kali Anda merencanakan, membuat, atau mengevaluasi pembuatan bank soal, Anda **DIWAJIBKAN** untuk mematuhi urutan linear pendidikan berikut. Anda tidak boleh membuat soal untuk *Layer* yang lebih tinggi jika *Layer* sebelumnya belum selesai secara tuntas.

## Urutan Progresi (Tidak Boleh Dilompati):
1. **LAYER 1: Core Foundation (Mata Pelajaran WAJIB)**
   - Semua mata pelajaran berstatus **Wajib** harus diselesaikan terlebih dahulu.
   - Meliputi: *Bahasa Indonesia, Matematika (Wajib), Bahasa Inggris, Literasi, Numerasi, Penalaran.*
   - Target saat ini: Selesaikan semua bank soal Matematika Wajib (World 2) sebelum menyentuh Tingkat Lanjut.
2. **LAYER 2: Profil Akademik**
   - Pemain (dan developer) menentukan target jurusan. (Penyesuaian rekomendasi).
3. **LAYER 3: Specialization (PILIH 2 MAPEL TINGKAT LANJUT)**
   - **HANYA BOLEH DIKERJAKAN JIKA LAYER 1 SUDAH SELESAI TOTAL.**
   - Meliputi: *Matematika Tingkat Lanjut, Fisika, Kimia, Biologi, Ekonomi, Sosiologi, dsb.*
4. **LAYER 4: TKA Arena**
   - Tes Kemampuan Akademik (Campuran Wajib + Pilihan).
   - Tahap paling akhir (*Endgame*).

**Peringatan Sistem Otomatis:**
Jika *user* (pengguna) atau Anda sendiri secara tidak sengaja menyarankan untuk melompat ke materi "Tingkat Lanjut" atau "TKA" sementara materi "Wajib" belum selesai secara utuh, Anda HARUS menghentikan eksekusi, membatalkannya, dan mengingatkan *user* tentang aturan **Alur Linear Wajib → Profil Akademik → Pilih Dua Mapel → TKA**.
