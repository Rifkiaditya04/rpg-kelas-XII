# Decision 006 — TKA Foundation + Camera/Character Prototype

**Date:** 14 August 2026
**Status:** TKA foundation recorded; visual prototype authorized; visual QA pending

## Decision

The project may establish the **Academic Planning Office / TKA Preparation** foundation now, before all future subject content is available.

This foundation is not an official TKA registration system and does not yet encode final subject-room rules.

## Evidence

Official TKA sources confirm the assessment structure and that its content considers competencies/materials applicable to Kurikulum Merdeka and Kurikulum 2013. The project therefore should use the official TKA assessment framework as assessment specification, rather than reconstructing a separate 2013 curriculum.

## Approved design direction

Future map structure may contain:
- Academic Planning Office;
- mandatory TKA preparation rooms;
- two selected choice-subject preparation rooms;
- future locked rooms for unselected subjects;
- progression locks for incomplete prerequisites;
- optional mastery gates for demonstrated readiness.

These are game design concepts, not official TKA rules.

## Camera/Character

Character Design v2 and Camera/Character Gameplay Specification v1 remain approved. A small visual prototype is now implemented for browser QA.

## Boundary

No final sprite production, final map production, mission system, progression system, or full TKA subject engine is implemented by this decision.

## Next gate

User live visual QA of `prototype/bahasa-indonesia/camera-character-prototype.html`.
If PASS, proceed to Mission System Design.
