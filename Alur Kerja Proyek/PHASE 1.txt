## Satu keputusan arsitektur yang sudah saya tetapkan

**Kita tidak akan membuat game dari Markdown mentah.**

Markdown ini adalah **raw knowledge source**.

Nanti kita buat Knowledge Base terstruktur seperti:

```text
knowledge/
└── bahasa-indonesia/
    ├── chapter-01.json
    ├── chapter-02.json
    ├── chapter-03.json
    ├── chapter-04.json
    └── index.json
```

Contohnya nanti:

```json
{
  "chapter": 1,
  "title": "...",
  "topics": [],
  "concepts": [],
  "skills": [],
  "exam_indicators": [],
  "game_mechanics": [],
  "source_pages": []
}
```

**Ini akan menjadi "otak akademik" game.**

Game engine kemudian hanya membaca knowledge base tersebut.

Dengan arsitektur ini, ketika nanti kita memasukkan **Matematika, Biologi, Fisika, dan mata pelajaran lainnya**, kita tidak perlu membuat game dari nol.
