# World 1 — KM Standard Chapter 1 Competency & Coverage Matrix v1

**Status:** DRAFT FOR USER REVIEW
**Phase:** Phase 3 — Content / Gameplay Rebaseline
**Source basis:** Bahasa Indonesia Kurikulum Merdeka Class XII Revised 2025 Student Book; Teacher Guide to be cross-validated when the exact repository artifact is available/readable.

## 1. Purpose

Map Chapter 1 activities into an educational Light RPG structure before drafting new questions. This matrix does not approve questions, mission implementation, or final question counts.

## 2. Source-verified Chapter 1 scope

The Student Book identifies Chapter 1 as **Mengomunikasikan Informasi Penting tentang Pendidikan dan/atau Pekerjaan** and lists activities A–H:

| ID | Activity | Source-verified focus | Initial gameplay role |
|---|---|---|---|
| A | Mengevaluasi Isi Rekaman Surat Resmi yang Disimak | evaluate information from a listened official-letter recording | Learn → listening/evidence challenge |
| B | Mengevaluasi Pesan Tersurat dan Tersirat dari Dua Surat Resmi yang Berbeda | evaluate explicit and implicit messages from two official letters | Learn → comparison/inference challenge |
| C | Merefleksikan Gagasan Berdasarkan Isi Surat Resmi | reflect on ideas based on official-letter content | NPC/context → reflection/decision challenge |
| D | Menganalisis Struktur dan Penggunaan Bahasa pada Surat Resmi | analyze structure and language use in official letters | Learn → document inspection |
| E | Mempresentasikan Kesalahan Kaidah Penulisan Contoh Surat Resmi | present errors in writing conventions in an example official letter | repair/diagnostic challenge |
| F | Menulis Surat Resmi dengan Memperhatikan Penggunaan Kata Baku dan Kalimat Efektif | write an official letter using standard words and effective sentences | guided composition / production challenge |
| G | Membalas Pesan Surat Resmi yang Diterima Menggunakan Layanan Pos Elektronik | reply to an official-letter message using electronic mail | scenario / communication challenge |
| H | Memublikasikan Poster Pengumuman Berdasarkan Surat Edaran yang Diperoleh | publish an announcement poster based on a circular letter | synthesis / publication challenge |

## 3. Coverage principle

A–H are **coverage anchors**, not an automatic 1:1 mission list. The final mission boundaries must be based on narrative coherence and learning coverage.

One mission may cover more than one activity when the same competency is naturally integrated. One activity may also require multiple challenges when its learning scope is broad.

## 4. Proposed learning loop

```text
School / communication area
        ↓
NPC establishes a realistic education/work communication problem
        ↓
Learn / explanation
        ↓
Guided example or evidence inspection
        ↓
Challenge
        ↓
Feedback + explanation
        ↓
Learning Evidence
        ↓
Progression / next eligible mission
```

## 5. Competency clusters

### Cluster 1 — Receive and evaluate information
Activities: A–B

Potential evidence:
- identifies relevant information;
- distinguishes explicit vs implicit meaning;
- compares messages;
- supports an evaluation with evidence.

Potential question types: MCQ, document inspection, comparison.

### Cluster 2 — Reflect and communicate interpretation
Activity: C

Potential evidence:
- connects information to a situation;
- explains a reasoned response;
- distinguishes personal reflection from unsupported guessing.

Potential question types: scenario choice, short structured response if renderer supports it.

### Cluster 3 — Inspect official communication
Activities: D–E

Potential evidence:
- identifies structural elements;
- recognizes language/register problems;
- identifies standard-word/effective-sentence issues;
- selects or repairs an appropriate form.

Potential question types: document inspection, MCQ, multi-select.

### Cluster 4 — Produce official communication
Activities: F–G

Potential evidence:
- selects appropriate standard wording;
- forms effective sentences;
- composes an appropriate response;
- adapts communication to electronic-mail context.

Potential question types: guided selection/reconstruction unless the renderer is expanded for authored text input.

### Cluster 5 — Transform information into public communication
Activity: H

Potential evidence:
- identifies essential information from a circular letter;
- selects what belongs in an announcement;
- organizes information for a poster/publication context.

Potential question types: document inspection, information selection, ordering/selection.

## 6. Gameplay translation constraints

The existing RPG architecture remains the implementation base:

- Explore;
- NPC/context;
- Learn/Context;
- Mission;
- Feedback;
- Learning Evidence;
- Progression;
- Training Hook / Training Room.

No RPG architecture rewrite is authorized by this matrix.

## 7. Question-count policy

**No fixed count is approved.**

Count will be determined after the coverage matrix is validated against the detailed Student Book sections and Teacher Guide guidance/assessment evidence.

The target is minimum sufficient coverage with varied challenge forms, not maximum question volume.

## 8. Copyright-safe authoring boundary

The source identifies what learners should study. Production content must be independently authored.

Do not copy textbook questions, passages, answer choices, examples, figures, or dialogue verbatim. Record provenance as concept/section reference rather than reproducing source text.

## 9. Prototype impact assessment

At this stage:

**Renderer:** retain.

**Mission engine:** retain unless the coverage matrix reveals a required unsupported interaction.

**Progression/evidence:** retain.

**Training Room:** retain; competency-specific remediation content will be generated later from the same approved KM source mapping.

**Potential future renderer extension:** authored-response/composition interaction may be considered if Activity F/G cannot be faithfully represented using the current supported question types. This is an open implementation question, not an approved change.

## 10. Required cross-validation before question drafting

1. Locate and read the exact Chapter 1 Student Book sections for A–H.
2. Locate and read the corresponding Teacher Guide Chapter 1 guidance/assessment.
3. Confirm each proposed competency cluster against those sources.
4. Identify required cognitive demand and evidence.
5. Determine which challenges can be represented by existing renderer types.
6. Identify any renderer gap before drafting questions.
7. Only then draft original question/content batches.
