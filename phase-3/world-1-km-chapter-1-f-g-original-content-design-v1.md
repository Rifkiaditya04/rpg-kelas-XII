## F–G gameplay translation
### F — Produce official communication
Focus on the learner's ability to plan and compose an appropriate official communication for a realistic school/work context. The game should teach decision-making and structure before challenging the player.

Proposed flow:
Explore context → NPC explanation → guided example → inspect/choose structural decisions → mission challenge → feedback → evidence.

### G — Respond through email
Focus on selecting and producing an appropriate response to an official communication in a realistic digital context. The game should distinguish purpose, audience, tone, completeness, and appropriateness without copying textbook examples.

Proposed flow:
Receive message → NPC/context explanation → guided example → identify response requirements → mission challenge → feedback → evidence.

## Interaction boundary
