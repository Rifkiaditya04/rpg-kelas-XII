## 4. Lane D — Writing / Revision

### Source anchors

- Student Book pp. 21–29: writing the application letter and CV; relevance, content, language, skills/experience, and closing/hope are explicit assessment dimensions.
- Student Book pp. 24–25: writing rubric with explicit dimensions for format, content/relevance, language/grammar, skills/experience, and closing/hope.
- Teacher Guide p. 32: Chapter I indicators include writing and editing.
- Teacher Guide pp. 36–39: authentic work context, decision making, and revision are part of the pedagogical framing.
- Teacher Guide pp. 75–77: summative indicators include improving opening/body/closing and creating application/CV text.

### Skill definition

Construct, revise, and evaluate application-letter/CV content so that it is relevant to the target vacancy, structurally appropriate, linguistically effective, and supported by applicant evidence.

### Suitable item forms

- MCQ for selecting the best revision.
- Multi-select for identifying all revisions that improve a draft.
- Document inspection for locating a specific revision defect.
- Before/after repair challenge for selecting the improved version.
- Scenario-based application review.

### Quality constraints

- Revision must have a source-grounded reason: relevance, format, language/grammar, skills/experience, or closing/hope.
- Distractors should represent realistic revision errors, not arbitrary stylistic preferences.
- Do not treat one stylistic wording as uniquely correct unless the source establishes the distinction.
- If a question asks for the `best` revision, the scenario must provide enough evidence for one defensible answer.
- Open-ended writing is not promoted into the generic renderer without a rubric-based assessment design.

## 5. Lane E — Presentation / Publication

### Source anchors

- Student Book pp. 30–34: presentation of application letter/CV and associated discussion/role-play/video assessment material.
- Student Book pp. 35–37: publication through various media and publication rubric.
- Teacher Guide pp. 32–35: clear presentation, digital communication ethics, presentation, and publication are explicit Chapter I indicators/time allocations.
- Teacher Guide pp. 36–39: presentation, publication, and digital communication are embedded in the functional-literacy/project framing.
- Teacher Guide pp. 75–77: summative framework includes communication/presentation-related Chapter I outcomes and production tasks.

### Skill definition

Choose and evaluate presentation/publication actions that communicate an application/CV clearly, appropriately, and ethically for the intended audience and medium.

### Suitable item forms

- Scenario MCQ for selecting the most appropriate presentation/publication action.
- Multi-select for identifying all appropriate publication checks.
- Document/message inspection for detecting publication or digital-communication problems.
- Sequencing for ordering a defensible publication/presentation workflow when the source supports a sequence.

### Quality constraints

- Do not invent platform-specific rules as textbook facts.
- Digital-communication ethics must be framed only to the extent supported by the Teacher Guide/source material.
- Presentation quality questions should test clarity, appropriateness, and communication purpose rather than subjective visual taste.
- Publication questions must distinguish content quality from medium choice.
- If a question refers to a digital medium, the scenario must contain enough context to make the intended audience/purpose clear.

## 6. Lane F — Integrated Application

### Source anchors

- Student Book Chapter I pp. 21–37 combines writing, CV preparation, presentation, and publication activities.
- Student Book pp. 23–25 connects vacancy relevance with writing quality and explicit rubric dimensions.
- Student Book pp. 30–37 extends the artifact into presentation and publication.
- Teacher Guide pp. 32–39 connects Chapter I indicators, authentic work context, decision making, revision, presentation, publication, and digital communication.
- Teacher Guide pp. 75–77 provides a summative frame spanning multiple cognitive levels and forms.

### Skill definition

Apply multiple Chapter I skills in one authentic job-application decision: interpret the vacancy, select relevant applicant evidence, improve the document, and choose an appropriate presentation/publication action.

### Suitable item forms

- Scenario-based MCQ for one best integrated decision.
- Multi-select for a complete set of appropriate actions.
- Document inspection for a multi-defect application package.
- Short ordered workflow only when the sequence is explicitly supported by the source context.

### Quality constraints

- Every integrated item must expose the evidence needed to make the decision; no hidden assumptions.
- The item must be decomposable into source-grounded subskills so answer verification remains auditable.
- Do not combine unrelated skills merely to make an item harder.
- Difficulty should come from integration/decision making, not from ambiguous wording.
- Explanations must identify which source-grounded criterion determines the answer.
